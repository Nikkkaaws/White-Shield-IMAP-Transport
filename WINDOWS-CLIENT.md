# WSIT Client for Windows

`WSIT-Client-Windows.exe` — единый клиент и установщик. При первом запуске он
копирует себя в `%LOCALAPPDATA%\Programs\WSIT`, создаёт ярлык в меню «Пуск» и
регистрируется в списке установленных приложений. Следующие запуски сразу
открывают клиент. Первая установка и удаление показывают в отдельном окне все
шесть стадий операции.

Сборка:

```powershell
.\scripts\build-windows-client.ps1
```

Готовый файл: `build/WSIT-Client-Windows.exe`.

Однократный импорт локальной конфигурации:

```powershell
.\build\WSIT-Client-Windows.exe -import-config .\config.yaml
```

Аккаунты проверяются до сохранения, затем клиент открывает основной интерфейс.
Файл `config.yaml` не копируется в каталог установки.

Почтовые пароли и код подключения сохраняются через Windows DPAPI. В разделе
«Настройки» доступна команда «Удалить WSIT»; она удаляет клиент, ярлык,
автозапуск и локальные настройки после закрытия окна.
