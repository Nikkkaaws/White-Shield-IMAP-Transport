# WSIT for Android

Лёгкий нативный клиент без root. Интерфейс написан на Kotlin без Compose и
тяжёлых UI-зависимостей; транспортное ядро собирается из общего Go-кода в AAR.

## Возможности

- запуск и корректная остановка WSIT в foreground service;
- локальный SOCKS5 для v2rayNG и других приложений;
- Client ID 1–255;
- импорт единого кода подключения из VPS-клиента вместо ручного ввода ключа;
- Rambler как готовый пресет и произвольные IMAP-серверы;
- несколько аккаунтов, включение, отключение, удаление и реальная проверка;
- разные IMAP-серверы для разных аккаунтов;
- живая статистика линий, потоков, RTT, очереди, приёма и отдачи;
- реальный тест скорости через локальный SOCKS5;
- профили производительности;
- автозапуск после загрузки телефона;
- журнал без паролей;
- шифрование конфигурации ключом Android Keystore.

## Сборка

Нужны Android SDK 36, Build Tools 36.0.0, NDK 28.2.13676358, JDK 17+,
Gradle Wrapper и `gomobile`.

```powershell
go install golang.org/x/mobile/cmd/gomobile@latest
go install golang.org/x/mobile/cmd/gobind@latest
.\scripts\build-android.ps1
```

APK появится в `build/WSIT-Android-debug.apk`.

## Установка на подключённый телефон

```powershell
.\scripts\install-android.ps1
```

Приложение слушает только адрес из настройки `Локальный SOCKS5`, по умолчанию
`127.0.0.1:1080`. Системный VPN и root приложению не требуются.
