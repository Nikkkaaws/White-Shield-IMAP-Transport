# WSIT Server Control

`WSIT-VPS-Client` — один самодостаточный файл для установки и управления
серверной стороной WSIT. На первом запуске он устанавливает самого себя,
регистрирует systemd-сервис и команды `wsit` и `/wsit`. Последующие запуски
сразу открывают обычный интерактивный менеджер.

## Сборка

```powershell
.\scripts\build-server-control.ps1 -Arch amd64
```

Готовый файл: `build/WSIT-VPS-Client-linux-amd64`.

## Запуск на VPS

```bash
chmod +x WSIT-VPS-Client-linux-amd64
./WSIT-VPS-Client-linux-amd64 -config ./config.yaml
```

При первом запуске клиент запросит `sudo`, установится в
`/usr/local/lib/wsit/wsit`, сохранит существующий `/etc/wsit/config.yaml` и
запустит сервис при корректной конфигурации. Установка и удаление показывают в
терминале все шесть стадий; после установки в том же окне открывается менеджер.
После этого меню открывается любой из команд:

```bash
wsit
/wsit
```

Управление: стрелки, Enter, Esc и Q. В интерфейсе доступны запуск и остановка,
обзор, аккаунты, IMAP-проверка, код подключения ПК/Android, настройки, журнал и
удаление клиента. При удалении `/etc/wsit/config.yaml` сохраняется.
